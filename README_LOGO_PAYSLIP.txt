PHASE 15G — PAYSLIP LOGO & OFFICIAL DECLARATION

Copy the app/payroll/payslips/page.tsx and payslips.css files into matching project paths. Copy public/flicks-licks-logo.png into your project public folder. Do not replace any other files.

The official declaration is shown only when the existing payslip ready flag is true. Preliminary statements are explicitly marked as not official.
