# Nex HR — Complete Phase 2 patch

## Installation
1. Back up PostgreSQL and your current working project.
2. Extract this ZIP into the project root, preserving relative paths.
3. Run `npm install` (adds mammoth and pdf-parse). Commit the updated package-lock.json generated by npm install.
4. Run `npx prisma generate`, `npx prisma migrate deploy`, `npx tsc --noEmit --pretty false`, then `npm run build`.
5. Deploy the code and migration to Railway. Do not run `prisma db push` in production.
6. Optional: configure `NEXHR_OPENAI_API_KEY` and `NEXHR_OPENAI_MODEL` on Railway. Without the key, Nex HR uses extractive retrieval (no AI paraphrasing).

## Security and limitations
- Retrieval is limited to approved, effective, nonexpired documents for the authenticated company and permitted visibility. Conversation history is restricted to the logged-in user and company.
- Answers are extractive passages from documents, not unconstrained AI advice. AI mode only accepts verbatim evidence passages; it falls back to extracted passages if validation fails.
- A strict zero-hallucination guarantee is not technically possible. Test retrieval quality and access permissions before enabling production use.
- This version extracts PDF text without dependable page numbering, so citations show document and version, but not a page unless available. Image-only PDFs require OCR and are not supported.
- Document text is extracted on demand. For large knowledge bases, introduce a tenant-scoped indexed extraction pipeline and usage limits before wide rollout.
- The app's existing session and permission gate (`nexhr.view`) controls access.
- No external web search is used. If an OpenAI API key is configured, excerpts are sent to OpenAI for processing; evaluate confidentiality and data-processing requirements before enabling it.

## Test
1. Ask about a fact in an approved document, then inspect its source citation.
2. Ask an unrelated question; confirm refusal.
3. Test unapproved, expired, HR-only, and other-company documents; they must not appear in citations.
4. Test switching tenants and users: conversations must remain private.
5. Test a PDF, DOCX and TXT file, including a scanned PDF (expected not searchable).
